# 测试环境验收记录

记录日期：2026-09-23。测试站：https://testmedusa.365d4u.com/ 。原 WordPress 生产站未切换。

## 支付验证

| 项目 | 结果 |
| --- | --- |
| PayPal Sandbox | 订单 #2，USD 169，Medusa `payment_status=captured` |
| Oceanpayment 嵌入式信用卡 | 用户提供的沙箱卡，完成模拟银行 3DS；订单 #3、#4，各 USD 169，均成功收款 |
| Oceanpayment 返回页面 | #4 自动显示订单确认；再次调用完成接口返回同一订单 |
| Oceanpayment 重复通知 | #4 的真实签名通知重放两次，仍只有一条 capture、收款金额 USD 169 |
| 篡改通知 | 修改回调金额但保留原签名，返回 HTTP 400 |
| 支付失败 | 模拟 3DS 失败，不创建订单；未批准的 PayPal 会话也不能完成订单 |
| Apple Pay | 用户已确认域名白名单，账单与购物车入口已启用；会话/组件联调通过，真实 Apple 钱包扣款待设备验收 |
| 自动化检查 | 11 项支付协议、签名、金额及 WordPress 密码兼容测试通过；后端和管理端构建通过 |

支付金额来自 Medusa，浏览器跳转和客户端成功标记不作为收款凭据。Oceanpayment 的 `billing_ip` 使用反向代理传递的真实客户端地址；Nginx 覆盖外部传入的转发头。银行卡输入留在 Oceanpayment iframe 内。

Oceanpayment 自动退款尚未实现，provider 明确返回未启用错误，不能将其视为完整退款联调验收。PayPal 退款代码已接入但尚未进行实际退款验证。

## 前端验证

38 个路由 HTTP 检查通过，没有发现页面脚本异常。未登录访问客户接口的 401 属于预期；`/hcinfo/` 内原有演示商品 ID 130 不在已发布商品数据中，其请求仍返回 404。

移动端 390×844 检查首页、全定制、半定制、现货、列表、评论、账户和商品页；未发现整页横向溢出。商品主图等待实际解码完成后截图复核。此检查不代表已逐像素比较全部页面。

已适配：原站页头页尾、目录内容和菜单、商品图片/视频、规格选择、购物车、结账、源站运费规则、客户登录、历史订单、收藏和分享、品牌筛选、评论翻页/提交/媒体上传、订阅保存。订阅目前保存到本项目数据库，不会声称已发送确认邮件。

## 尚未完成的完整迁移验收

- 全定制、个性化产品及订金流程的全部交互和版式逐项比对；现有商品页使用统一迁移模板。
- 原站全部优惠、促销时间规则及专用产品插件行为的等价验证；直播/秒杀内容目前包含源站快照。
- 账户地址编辑、注册欢迎信、密码重置邮件、客户订单备注通知、人工订单邮件重发，以及营销订阅向原邮件系统的同步。自动客户账单邮件、付款成功内部通知和带 PDF 的付款人确认邮件已在测试站迁移，详见 `email-parity-audit.md` 与 `payment-business-rules.md`。
- 原站 wpDiscuz 商品/博客评论交互、相关外部业务系统接口和所有后台内容编辑工作流。
- Apple Pay 真实设备钱包授权与扣款验收；Oceanpayment 自动退款；生产凭据和生产切换。

因此本项目当前是可运行、核心支付已联调的迁移测试环境，**不能宣称已完整复刻全站或达到生产切换条件**。
